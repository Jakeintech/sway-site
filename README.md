# sway-site

Public website for **Sway: Bird Puzzle**, a balance game for iPhone: get the birds to bed before the branch tips.
Live at https://jakeintech.github.io/sway-site/ (GitHub Pages from `main`).

- Pages are written by `scripts/build.py` (standard library only). Edit the copy there, run it, read the pages, commit.
- Images in `assets/img/shots` are real captures from the App Store build (the app repo's `appstore/screenshots/raw/iphone`).
- Never state a price; the App Store shows it in the reader's currency. Every claim must be true of the shipped build.
- The privacy policy must match the App Store label (Data Not Collected).
